# Data Analysis Sim

데이터 분포를 넣으면 KDE·모멘트·분위수 등 의미 있는 값을 뽑아 주는 분석 시뮬레이터.
데이터가 없으면 분포·파라미터·seed·샘플 수 N 을 정해 합성 데이터로 시험한다.

**실행**: `Data Analysis Sim.bat` 더블클릭 (http://localhost:5002 — 고정 포트, 이미 실행 중이면 브라우저만 연다) · 통합 런처에서 열면 백엔드가 자동으로 뜬다.

## 구조

화면은 웹, 계산은 Python(NumPy·SciPy) 백엔드. 원본 데이터는 서버 메모리에 한 번만 올리고(합성 데이터는 서버에서 바로 생성), 브라우저에는 결과(통계표·KDE 곡선·축약 시계열)만 보낸다.

```
data_analysis_sim/
├── server.py            Flask API + 정적 파일 (포트 5002)
├── launcher.py          .bat 이 실행하는 진입점 (패키지 없으면 안내창)
├── analysis/            분석 엔진 — Flask 와 무관, 노트북에서도 import 가능
│   ├── synth.py         seed 고정 합성 데이터 (15개 분포 + 시계열 성분), 이론값
│   ├── descriptive.py   위치·산포·모멘트·분위수

│   ├── risk.py          VaR·CVaR(양쪽 꼬리, 이론값), Hill 꼬리지수, 이상치, MDD
```

## 현재 기능

### 개요 탭 (1단계)

- **입력**: 합성 데이터(정규·균등·지수·로그정규·감마·베타·와이블·t·라플라스·코시·파레토·검벨·정규혼합·포아송·이항) 또는 내 데이터(파일 끌어놓기 / 붙여넣기, 여러 열이면 열 선택)
- **시계열 성분**(선택): fs, 선형 추세, AR(1) φ(분산 유지), 랜덤워크, 사인 3개 — 켜면 이론값 비교는 꺼진다
- **통계량**: 평균·95% CI·중앙값·최빈값·절사/기하/조화평균, 분산·표준편차·SEM·범위·IQR·MAD·CV, 왜도·초과첨도(보정 G1/G2 와 g1/g2, 표준오차), 1~4차 원점·중심 모멘트, 1~99% 분위수
- **이론값 비교**: 합성 데이터면 모든 항목 옆에 모집단 값과 차이 (코시 평균처럼 정의되지 않으면 "정의 안 됨", t 분포 ν≤4 첨도는 ∞)
- **그래프**: 히스토그램 + KDE(Silverman/Scott, 배율 슬라이더) + 참 PDF/PMF, 박스플롯, 샘플 순서 시계열
- 꼬리가 긴 데이터(코시·파레토)는 보기 범위를 Q1−6·IQR ~ Q3+6·IQR 로 자동 제한 (전체 범위로 전환 가능)

### 리스크·꼬리 탭 (2단계)
- **VaR·CVaR** — 신뢰수준 90 / 95 / 97.5 / 99 / 99.5%, 왼쪽·오른쪽 꼬리 모두. 값은 데이터 단위 그대로(부호 뒤집지 않음): 수익률이면 왼쪽, 손실액이면 오른쪽 꼬리가 위험 쪽
  - 표본 CVaR 은 분위수 함수의 정확한 계단 적분 `(Σ_{i≤k} x₍ᵢ₎ + (nα−k)·x₍ₖ₊₁₎)/(nα)`
  - 합성 데이터면 이론 VaR·CVaR 도 표시 (연속 분포는 분위수 함수 적분, 정규혼합은 닫힌 식, 이산 분포는 원자 보정 합). 꼬리 평균이 없으면(코시) ±∞
- **꼬리 두께** — Hill 꼬리지수 α(중앙값 기준, k=√N), (CVaR−중앙값)/(VaR−중앙값) 와 정규 기준값, 꼬리 폭 비
- **이상치** — IQR×1.5, IQR×3, |z|>3, |수정 z|>3.5 규칙별 개수와 정규분포라면 기대되는 비율, 가장 극단적인 값 10개
- **최대 낙폭(MDD)** — 값을 증분으로 보고 누적(수익률) / 수준 그대로(가격) 중 선택, 고점·저점·회복 시점과 수중 기간

### 분포 적합·검정 탭 (2단계)
- **정규성 검정** — Shapiro–Wilk(N>5000 이면 무작위 5000개), D'Agostino K², Jarque–Bera, Lilliefors(KS), Anderson–Darling, 왜도·첨도 검정. N 이 매우 크거나 작을 때 해석 주의 문구
- **분포 적합** — 연속 13종(정규·t·라플라스·로지스틱·코시·검벨·균등·지수·로그정규·감마·와이블·파레토·베타) 또는 이산 4종(포아송·기하·음이항·이항)을 MLE 로 적합, AIC 순위·ΔAIC·BIC·Akaike 가중치·KS
  - 파라미터 표기는 합성 데이터 생성기와 같아서 참 값과 바로 비교된다 (합성 데이터면 참 분포에 표시)
  - 양수 전용 분포는 위치 0 고정(2-모수), 데이터에 0 이하가 있으면 제외. N > 50,000 이면 파라미터만 무작위 50,000개로 추정
- **그래프** — 히스토그램 위 적합 PDF/PMF 겹쳐 보기(표에서 선택), Q-Q 그림(기준 분포 선택, 꼬리 쪽 점 밀도 높임), ECDF vs 적합 CDF

### 시계열 탭 (3단계)
샘플 순서를 시간으로 본다 (시간 = 샘플 번호 / fs).
- **이동 통계·추세** — 이동평균 ±1σ 띠(창 크기 지정), 선형 추세의 기울기·R²·전체 변화
- **검정** — Ljung–Box Q(독립성), 런 검정(무작위성), ADF(H0 단위근)·KPSS(H0 정상) 두 방향의 정상성 검정과 종합 판단, 추세 기울기 t 검정, 구간 평균(ANOVA)·분산(Levene) 일정성
- **ACF / PACF** — ACF 는 FFT 로, Bartlett 95% 띠와 백색잡음 기준선. PACF 는 Durbin–Levinson. 처음 무상관 수준에 들어가는 시차
- **구간별 통계** — K개 연속 구간의 평균±σ, 왜도, 첨도
- **DFA** — 창 크기별 요동 F(s) 의 기울기 α 와 Hurst H (α ≤ 1 이면 H = α, 랜덤워크처럼 α > 1 이면 H = α − 1)
- N 이 크면 ADF·KPSS 는 앞 100,000개, DFA 는 앞 1,000,000개 구간으로 계산

### 주파수 탭 (3단계)
- **FFT 진폭 스펙트럼** — 추세 제거(선형/평균/안 함) + Hann 창, 진폭 보정으로 사인 A 가 높이 A 로 보인다. 봉우리 주파수는 로그 진폭 포물선 보간으로 빈 사이까지 추정
- **주요 주파수 표** — 주파수, 주기, 진폭, 파워 비율
- **Welch PSD** — 구간 길이 선택(자동 = 약 8구간), 50% 겹침
- **스펙트럼 지표** — 중심·대역폭·중앙 주파수·85% roll-off, 스펙트럼 엔트로피와 평탄도(1 = 백색잡음)
- **스펙트로그램** — STFT(창 길이 선택), dB 히트맵
- 주파수 단위: 합성 데이터는 생성할 때의 fs [Hz]. 업로드 데이터는 "현재 데이터" 카드에서 fs 를 입력하거나 시간 열을 고르면 간격의 중앙값으로 정한다 (간격이 1% 넘게 들쭉날쭉하면 경고). 모르면 cycles/sample

### Seed / N 테스트 탭 (4단계)
데이터가 없어도 "이 분포에서 N 개면 추정값이 얼마나 믿을 만한가"를 본다. 왼쪽 합성 데이터 설정의 분포·파라미터를 쓴다.
- seed 마다 최대 N 개를 `default_rng(시작 seed + s)` 로 한 번 뽑고, 각 N 은 그 앞쪽 N 개를 쓴다 → seed 하나가 N 을 따라가는 경로 하나
- 통계량 10개: 평균, 표준편차, 왜도, 초과첨도, 중앙값, 양쪽 VaR·CVaR 95%, KS 거리 sup|Fₙ − F|
- 통계량마다 참값, 최소·최대 N 의 오차, **수렴 기울기**(log 오차 대 log N)와 판정: −0.5 근처면 1/√N 수렴, −0.15 ~ −0.4 면 느린 수렴(두꺼운 꼬리), 0 근처면 수렴하지 않음
  - 오차 = seed 간 RMSE. 참값이 정의되지 않거나 무한대면(코시 평균, t 분포 ν≤4 첨도 등) seed 간 IQR
- 그래프: seed 별 경로 + seed 간 5~95%·25~75% 띠 + 중앙값 + 참값, 오차 대 N (log–log, 1/√N 기준선), N 별 편향·표준편차·RMSE 표
- 한도: N ≤ 1,000,000, seed ≤ 100, seed × 최대 N ≤ 20,000,000

## 통계 관례

| 값 | 정의 | 일치 대상 |
|---|---|---|
| 분산·표준편차 | 불편 (N−1) | `np.var(ddof=1)` |
| 왜도 G1 / 초과첨도 G2 | 표본 보정값 | pandas `.skew()` `.kurt()`, Excel |
| 왜도 g1 / 초과첨도 g2 | m3/m2^1.5, m4/m2²−3 | `scipy.stats.skew/kurtosis(bias=True)` |
| 분위수 | 선형 보간 (type 7) | `np.percentile` 기본값 |
| PACF | Yule–Walker (Durbin–Levinson) | `statsmodels pacf(method="ywm")` |
| Ljung–Box | Q = n(n+2) Σ ρₖ²/(n−k), FFT ACF 로 계산 | `statsmodels acorr_ljungbox` |
| KDE 대역폭 | Silverman 0.9·A·n^(−1/5), Scott 1.059·A·n^(−1/5), A=min(σ, IQR/1.349) | statsmodels |

KDE 는 격자(2048점)에 선형 binning 후 FFT 합성곱으로 계산한다. 정확한 KDE(`scipy.stats.gaussian_kde`) 대비 오차는 봉우리 높이의 1e−5 수준이고, 500만 샘플도 0.2초 안에 끝난다.
